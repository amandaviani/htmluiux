DZAL KAF RO’ — WEBSITE PUBLIK (TANPA ADMIN)

Halaman yang tersedia:
- index.html — otomatis membuka Beranda
- beranda.html — Beranda
- katalog.html — Katalog Produk
- detail.html — Detail Produk
- tentang-kami.html — Tentang Kami
- faq.html — FAQ & Bantuan
- lokasi.html — Lokasi & Jam Buka

File pendukung:
- style.css — desain dan responsive layout seluruh halaman
- assets/ — gambar produk, peta, dan logo Dzal Kaf Ro’

Admin telah dihapus dari paket ini:
- Tidak ada halaman login admin.
- Tidak ada dashboard atau menu pengelolaan admin.
- Tombol Admin di navigasi website telah dihapus.

Cara menjalankan di XAMPP:
1. Ekstrak folder dzal-kaf-ro ke C:\xampp\htdocs\homade
2. Pastikan index.html, halaman HTML, style.css, dan folder assets berada langsung di dalam folder homade.
3. Jalankan Apache.
4. Buka http://localhost/homade/

Fitur publik:
- Katalog dan pencarian/filter produk
- Detail produk
